# Prall Mini

Portrait-3D-Touch-PWA: eine candyfarbene Kugel auf einem Spieltisch anstoßen — sie prallt an Blöcken ab.

## Constraints

- Mobile first
- Installierbare PWA
- Keine Accounts, kein Backend, keine In-App-Käufe

## Status

**M1 in Arbeit** auf Branch `feature/m1-prall`.

Hauptbranch `main` enthält nur Projektdokumentation. Spielcode wird nicht nach `main` gemerged, solange QA nicht freigibt.

## Stack

TypeScript, Vite, vite-plugin-pwa, Three.js, cannon-es.
