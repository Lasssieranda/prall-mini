# Projekt

Ein Bildschirm: Spieltisch von schräg oben. Kugel anflicken, sie springt, Blöcke stehen im Weg. Candy-Look, Three.js + cannon-es.

Keine Reliktinseln-Systeme (Inseln, Relikte, Idle, 2D-Canvas-Layer, Economy, Save-Schema).

## M1-Abnahme

- Portrait-PWA
- Flick bewegt die Kugel
- Bounce auf Tisch und Blöcken
- Runterfallen setzt nach 1,2 s zurück
- Version im HUD
- Pause, wenn der Tab versteckt ist (`document.hidden`)
